The result of the last check of this blog. The list shows what is to fix; the filter "Status" shows the rest.

Link
A link of an entry, asked to its web site. "To verify" means the site gave no clear answer (it may refuse robots): open the link to know.
File
An image or a file of an entry which should be in the media library of the blog and is not there anymore.
Unused media
A media of the media library no entry uses. A theme or a widget may still use it: look at it before deleting it.
Selected lines
Check them again after fixing their entry, ignore those which are not a problem, or delete unused media for good. "Check again" also stops ignoring a line.
