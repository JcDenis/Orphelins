The links and the files of the entries, as found by the last check of this blog. The list shows what is to fix; the filter "Status" shows the rest.

Link
A link of an entry, asked to its web site. "To verify" means the site gave no clear answer (it may refuse robots): open the link to know.
File
An image or a file of an entry which should be in the media library of the blog and is not there anymore.
Result
Leave the pointer on a result to read its details, like the address a link is redirected to.
Selected lines
Check them again after fixing their entry, ignore for good those which are not a problem (the filter "Status" still shows them), or forget them: a forgotten line leaves the list until a next check finds it again. "Check again" also stops ignoring a line.
